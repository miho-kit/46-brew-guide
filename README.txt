Brew Guide

2つの抽出レシピを切り替えて使えるPWAです。

【4:6メソッド】
・豆量：15g / 20g / 30g
・焙煎度と湯温：浅煎り93℃ / 中煎り88℃ / 深煎り83℃
・味わい：甘く / バランス / 明るく
・濃さ：軽め（3回注ぎ） / 中間（4回注ぎ） / 基本（5回注ぎ）
・初期選択：味はバランス、濃さは基本
・レシピごとの終了時間でタイマーを自動停止

【長崎愛美 7投式】
・豆量：17.5g
・総湯量：210g
・30g × 7投
・20秒間隔：0:00 / 0:20 / 0:40 / 1:00 / 1:20 / 1:40 / 2:00
・1〜4投目：90℃
・5〜7投目：75℃
・挽き目：約1200μm・粗挽き
・7投目以降は落ち切り時間が固定されていないため、タイマーを自動停止せず継続

【共通】
・抽出タイマー付き
・抽出中は設定とモード切替をロック
・対応端末では抽出中の画面スリープを防止
・オフライン起動対応
・下部にコーヒーを淹れるペンギンのイラスト

公開方法：
GitHub Pages / Netlify / Vercel など、HTTPS配信できる静的ホスティングにフォルダ一式をアップロードしてください。
iPhoneではSafariで公開URLを開き、共有 → ホーム画面に追加 でアプリ風に使えます。
