Brew Guide

3つの抽出レシピを切り替えて使えるPWAです。

【4：6メソッド】
・豆量：15g / 20g / 30g
・総湯量：豆量 × 15
・焙煎度と湯温：浅煎り93℃ / 中煎り88℃ / 深煎り83℃
・味わい：甘く / バランス / 明るく
・濃さ：軽め / 中間 / 基本（しっかり）
・初期選択：味はバランス、濃さは中間
・最初の40％を2投、残り60％を濃さに応じた回数で分割
・甘く：40：60 / バランス：50：50 / 明るく：60：40
・レシピごとの終了時間でタイマーを自動停止

【7投式】
・豆量：17.5g
・総湯量：210g
・30g × 7投
・20秒間隔：0:00 / 0:20 / 0:40 / 1:00 / 1:20 / 1:40 / 2:00
・1〜4投目：90℃
・5〜7投目：75℃
・粗挽き
・TIMEMORE C2：30〜31クリック目安
・1:10に75℃への温度切替を通知
・7投目以降は落ち切り時間が固定されていないため、タイマーを自動停止せず継続

【カフェオレ】
・豆量：15g / 20g
・カフェオレを開いたときは15gを初期値にする
・豆：お湯＝1：10
・15gは150g、20gは200gのお湯
・中挽き
・5投で抽出
・15gは30g × 5投、20gは40g × 5投
・抽出液の目安：15gは120g、20gは160g
・牛乳比率：3：7（バランス）/ 4：6（コーヒー強め）
・初期比率：4：6

【共通】
・4：6メソッドと7投式に抽出タイマー付き
・抽出中は設定とモード切替をロック
・対応端末では抽出中の画面スリープを防止
・オフライン起動対応
・下部にフッター画像を表示

公開方法：
