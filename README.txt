Brew Guide

3つの抽出レシピを切り替えて使えるPWAです。

【4:6メソッド】
・豆量：15g / 20g / 30g
・焙煎度と湯温：浅煎り93℃ / 中煎り88℃ / 深煎り83℃
・味わい：甘く / バランス / 明るく
・濃さ：軽め（3回注ぎ） / 中間（4回注ぎ） / 基本（5回注ぎ）
・初期選択：味はバランス、濃さは基本
・レシピごとの終了時間でタイマーを自動停止

【7投式】
・豆量：17.5g
・総湯量：210g
・30g × 7投
・20秒間隔：0:00 / 0:20 / 0:40 / 1:00 / 1:20 / 1:40 / 2:00
・1〜4投目：90℃
・5〜7投目：75℃
・挽き目：約1200μm・粗挽き
・1:10に75℃への温度切替を通知
・7投目以降は落ち切り時間が固定されていないため、タイマーを自動停止せず継続

【カフェオレ】
・豆量：15g / 20g
・豆：お湯＝1：10
・15gは150g、20gは200gのお湯
・中挽き
・5回に分けて注湯
・15gは30g × 5投、20gは40g × 5投
・各投、お湯が落ち切ったら次の注湯へ進む
・固定時間ではなく、タイマーを動かしながら「次の注湯」ボタンで手動進行
・抽出後のコーヒー液を入力すると、3：7（バランス）/ 4：6（コーヒー強め）の牛乳量と完成量を計算

【共通】
・抽出タイマー付き
・抽出中は設定とモード切替をロック
・対応端末では抽出中の画面スリープを防止
・オフライン起動対応
・下部にコーヒーを淹れるペンギンのイラスト
